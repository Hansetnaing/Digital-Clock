# World Clock

A responsive browser-based world clock built with plain HTML, CSS, and JavaScript. It shows live time and date information for a selection of locations across Asia, Oceania, and UTC.

## Features

- Live clock that updates every second
- 12-hour and 24-hour display modes
- Region and location filters
- Accurate IANA time zones, including daylight-saving-time changes
- One-click switch to the visitor's local time zone
- Responsive layout for phones, tablets, and desktop screens
- Keyboard-friendly, accessible form controls

## Run the project

No installation or build step is required.

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Choose a region and location, then use the format button to change between 12-hour and 24-hour time.
